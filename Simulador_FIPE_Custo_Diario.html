Simulador · Frontend estático · API por placa

Proteção veicular com consulta por placa e visual de apresentação.

Esse front foi preparado para rodar separado do backend no Easypanel. Você informa a URL da API uma vez, consulta a placa e vê a estimativa em tempo real com valor FIPE, plano recomendado e três faixas de proteção.

Independente Funciona em serviço separado, sem depender de `file://` nem do backend no mesmo domínio.
Configurável A URL da API pode ser salva no navegador ou passada por query string `?api=`.
Pronto para demo Se o backend responder, o simulador monta os planos e exibe a cotação na hora.
